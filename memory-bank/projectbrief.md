# Project Brief

Mali müşavirlere 5.000 TL’ye satılacak, ayrı kopya modelinde hazır web sitesi.

## Hedef

- Kurumsal vitrin sitesi
- Admin paneli ile blog yönetimi
- Site başlığının admin tarafından değiştirilebilmesi
- Diğer sayfa içerikleri standart şablon

## Kapsam dışı (şimdilik)

- Multi-tenant tek sistem
- Müşteriye özel tüm alanları panelden düzenleme
